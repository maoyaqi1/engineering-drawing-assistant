# 工程制图学习助手（微信小程序）

一个无需第三方依赖的原生微信小程序教学 MVP，用于演示空间点与第一角投影三视图之间的对应关系。

> 当前版本：**v0.6.2**（在 v0.6.1 基础上修复名单管理：导入逐条去重防止学号重复、移除按记录 _id 精确删除该条并给出成功/失败提示）

## 运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. 没有 AppID 时可使用测试号；准备真机发布时，将 `project.config.json` 中的 `appid` 替换为自己的小程序 AppID。
5. 点击“编译”，再使用“预览”二维码在手机微信中运行。

## 当前功能

- 空间直角坐标系和等轴测示意。
- 第一角投影的正视图、俯视图和左视图。
- 当前教学对象统一位于第一分角，交互坐标范围为 0～8。
- 点模块包含一般点、原点、三投影面和三坐标轴预设。
- 直线模块包含一般线、三类平行线和三类投射线预设。
- 平面模块包含一般面、三类平行面和三类投射面预设。
- 截切模块包含三棱锥、五棱柱、圆柱、圆锥、圆球和圆环。
- 截平面支持水平面、侧平面快捷位置及 0°～180° 正垂面连续角度，偏移可调，截交线及三视图实时更新。
- 曲面立体投影按制图线型显示轮廓、不可见线和细点画中心线。
- 在展开投影图中拖动点、直线端点或平面顶点，空间视图实时联动。
- 投射辅助线、坐标说明和教学提示。
- 手机安全区和大屏设备的响应式布局。
- 微信登录与学生注册（学校、姓名、学号）。
- 学生名单管理（教师批量导入学号），名单内可免费使用 AI 教师提问，名单外仅可使用互动工具。
- 基于教师课件与备课笔记整理的 AI 教师知识库（投影、直线、平面、立体、截交、相贯、制图、零件图、轴测图等）。
- 学习效果调查问卷（含 AI 教师使用情况与帮助程度反馈）。

## 技术说明

项目使用微信小程序原生 WXML、WXSS、JavaScript 和 Canvas 2D，无 npm、构建步骤或外部资源。Canvas 是渲染层；空间坐标是几何真值，三个投影均由同一个点模型派生。

## 当前限制

当前已实现点、直线、平面和正垂面截切教学；尚未包含实体相贯线模块。三维区域是适合移动端的等轴测教学示意，并非可旋转的 Three.js/WebGL 场景。圆柱、圆锥、圆球和圆环的截交线采用独立高精度参数网格近似，显示线框密度不会改变计算精度。

## 微信网页版

网页入口为 `web/index.html`，可直接打开测试。网页版复用 Version 1.0 的几何与 Canvas 逻辑，公众号部署说明见 `web/README.md`。
