## 3. 冻结的产品行为

### 产品介绍与育人理念

- 首页产品名称只链接到“关于工程制图学习助手”；
- “动脑思考 / 动手探索 / 善用工具”分别进入独立页面；
- 三页使用统一模板，并共同展示课堂学习约定；
- 学生被明确要求携带铅笔、直尺、圆规和橡皮，先用铅笔轻画，再用尺规复核、加深；
- 页面不创建学习会话、不写学习记录。

### 联系渠道

- 教师问题反馈 QQ 群：`582350202`，入群要求实名；
- 团队邮箱：`maoyq@ahjzu.edu.cn`；
- 微信公众号：“流金岁月”，原始 ID `gh_00107ceb1e4b`；
- QQ 群和邮箱仅展示纯文本；
- 只有“流金岁月”文字可点击，通过 `wx.openOfficialAccountProfile` 打开公众号主页，失败时复制名称并提示搜索。

### 版本更新

- 启动时调用 `wx.getUpdateManager()` 检查新版本；
- 新版本下载完成后主动提示用户立即重启或稍后处理；
- 用户确认后调用 `applyUpdate()`；
- 下载失败时提示关闭小程序后重新打开；
- 关于页优先显示当前安装包版本，版本缺失时使用集中配置回退。

### 教学术语

- 学生端产品介绍、能力页和问卷统一使用“空间思维”“理解”“判断”“推理”等表述；
- AI 教师 Prompt 与相关本地知识库同步清理“想象”表述；
- 上述云函数源码变更随 Git 版本冻结，但未部署，线上 AI 口径仍需另行验证。

### 既有能力

- 点、线、面、投影体系、立体投影和平面与立体相交能力保持；
- 登录注册、学习会话、问卷邀请、AI 准入与教师工作台权限不变。
