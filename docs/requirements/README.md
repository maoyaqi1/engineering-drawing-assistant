需求编号统一采用“业务域前缀 + 序号”（如 `SYS-01`、`IAM-12`），前缀含义和完整范围见统一规格的“需求编号说明”，不在本页重复维护。

## 使用规则

1. 阅读、评审或实施需求时，以统一规格为准。
2. 需求完成并通过现有环境验证后，必须回写统一规格。
3. 回写时同步检查相关章节、需求编号、验收、当前限制和跨域影响，删除被替代或重复的内容。
4. 不按日期新增 `REQ-xxx.md`，也不新增平行的“补充说明”作为第二份当前规格。
5. 历史方案、实施计划和测试报告只作为追溯证据，不能覆盖统一规格。
6. 新增或废弃需求编号时，同步更新统一规格顶部的编号说明和所属篇章的编号范围。
