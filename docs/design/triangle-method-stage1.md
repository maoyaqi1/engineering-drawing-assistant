## 3. 数学正确性审查

### 3.1 统一输入

给定：

```text
A(xA, yA, zA)
B(xB, yB, zB)
Δx = xB - xA
Δy = yB - yA
Δz = zB - zA
```

### 3.2 投影长度

与当前第一角坐标定义一致：

```text
lH = sqrt(Δx² + Δy²)  // 水平投影长度
lV = sqrt(Δx² + Δz²)  // 正面投影长度
lW = sqrt(Δy² + Δz²)  // 侧面投影长度
```

实现建议使用 `Math.hypot(Δx, Δy)`，它在中间量接近极大或极小时比手写平方和更稳健。

### 3.3 实长与倾角

```text
L = sqrt(Δx² + Δy² + Δz²)
α = atan2(|Δz|, lH)  // 对 H 面
β = atan2(|Δy|, lV)  // 对 V 面
γ = atan2(|Δx|, lW)  // 对 W 面
```

结果均为弧度，界面显示时转成度数。`L` 也可直接使用：

```text
Math.hypot(Δx, Δy, Δz)
```

并对以下恒等式做测试：

```text
L = sqrt(lH² + Δz²)
L = sqrt(lV² + Δy²)
L = sqrt(lW² + Δx²)
```

以 `A(2,2,6)`、`B(6,5,2)` 为例：

```text
Δx=4, Δy=3, Δz=-4
lH=5, lV=sqrt(32)≈5.657, lW=5
L=sqrt(41)≈6.403
α≈38.66°
β≈27.94°
γ≈38.66°
```

**【代码事实】** 使用 `Math.hypot` 独立复算，三条实长恒等式误差均为浮点舍入级，公式与当前坐标定义一致。

### 3.4 特殊位置与退化

| 情形 | 结果 | 教学处理 |
| --- | --- | --- |
| A=B | `L=0`，角度无定义 | 拒绝进入构造，提示两端点不能重合 |
| 水平线 `Δz=0` | `lH=L`，`α=0°` | 指出 H 投影直接反映实长 |
| 正平线 `Δy=0` | `lV=L`，`β=0°` | 指出 V 投影直接反映实长 |
| 侧平线 `Δx=0` | `lW=L`，`γ=0°` | 指出 W 投影直接反映实长 |
| 铅垂线 `Δx=Δy=0` | `lH=0`，`α=90°` | H 投影积聚为点，三角形退化 |
| 正垂线 `Δx=Δz=0` | `lV=0`，`β=90°` | V 投影积聚为点 |
| 侧垂线 `Δy=Δz=0` | `lW=0`，`γ=90°` | W 投影积聚为点 |
| 一般位置 | 三个投影长度均小于 `L` | 三个投影都不能直接反映实长 |

**【设计建议】** 把“特殊位置”作为探索模式的扩展验证，不作为一般位置样板的首屏强制路径。

### 3.5 数值策略

建议把不同语义的容差分开：

- 几何退化：`LENGTH_EPSILON = 1e-8`；
- 边长/坐标差比较：`abs(a-b) <= max(1e-8, scale*1e-8)`；
- 垂直判定：归一化向量点积绝对值 `<= 1e-5`，或使用与角度等价的余弦阈值；
- 作图吸附：默认模型步长 `0.1`；
- 作图验收：模型单位 `0.08–0.12`，初始实现建议 `0.1`；
- 结果显示：实长保留 2 位小数，角度保留 1 位小数；
- 用户输入答案：实长容差至少覆盖显示精度。

所有渲染容差和教学判定容差必须命名并分项说明，不能共用一个“万能 EPS”。

## 5. 页面与交互原型

### 5.1 页面结构

建议从上到下：

1. 顶部：返回、知识点标题、模式切换；
2. 问题卡：给定 A/B 坐标和“目标倾角/实长”；
3. Canvas：空间验证 + 二维构造；
4. 当前步骤提示：一句目标，一句操作提示；
5. 操作区：选择、撤销、重置、提示；
6. 结果区：实长、角度、坐标差、当前误差；
7. 完成区：重做、切换另一种投影、查看空间验证。

不用首版自定义组件。页面控件数量有限，用 WXML 组合即可减少跨页面接口设计。

### 5.2 Canvas 分区

建议单 Canvas 两个区域：

```text
┌────────────────────────────┐
│ 空间直线 A-B               │
│ A、B、三面投影和辅助线      │
├────────────────────────────┤
│ 二维构造区                 │
│ 选定投影长度的底边 + 直角  │
│ 边 + 实长斜边              │
└────────────────────────────┘
```

PAD/宽屏改为左右：

```text
┌──────────────┬────────────────────┐
│ 空间直线     │ 二维直角三角形构造 │
│ 投影关系     │ 步骤和反馈         │
└──────────────┴────────────────────┘
```

### 5.3 引导学习模式

建议状态：

1. `INTRO`：阅读问题和已知端点；
2. `JUDGE_PROJECTION`：判断哪个投影直接反映实长；
3. `CHOOSE_BASE`：选择用于构造的投影（H/V/W）；
4. `IDENTIFY_DELTA`：选择投影时缺失的坐标差；
5. `DRAW_BASE`：确认/拖出投影底边；
6. `DRAW_HEIGHT`：从底边端点拖出垂直坐标差；
7. `DRAW_HYPOTENUSE`：连接成斜边；
8. `INPUT_RESULT`：填写或选择实长与角度；
9. `VERIFY_SPACE`：空间模型高亮同一组 Δ 分量；
10. `COMPLETE`：显示构造、公式和结果。

一般位置直线的第一问，正确结论是“H/V/W 都不能直接反映实长”，而不是三选一的 H/V/W。

### 5.4 自主探索模式

探索模式不强制顺序，但保持相同的数据和校验：

- 可直接拖动 A/B 改变直线；
- 可切换 H/V/W 构造基底；
- 可拖动垂直边长手柄；
- 可连接斜边；
- 每一步完成后即时显示“当前边长、是否垂直、与目标差多少”；
- 错误时停留在原步骤，不自动补齐；
- 只显示操作结果，不提前显示最终答案。

### 5.5 真正参与关键构造的方式

系统不得直接画完三角形。至少要求：

1. 学生选择投影面和缺失的坐标差；
2. 学生拖动垂直边端点，吸附到目标长度；
3. 学生主动连接斜边；
4. 引导模式要求学生提交实长/角度。

底边可以由系统从所选投影预置，因为它是已知投影，不是本题的关键待构造量。垂直边和斜边必须由学生完成。

### 5.6 直角三角形的三种合法构造

| 选择面 | 底边 | 垂直边 | 斜边 | 夹角 |
| --- | --- | --- | --- | --- |
| H | `lH` | `|Δz|` | `L` | H 面倾角 `α` |
| V | `lV` | `|Δy|` | `L` | V 面倾角 `β` |
| W | `lW` | `|Δx|` | `L` | W 面倾角 `γ` |

**【设计建议】** 角度按教材定义取 0°–90°，因此三角形向上或向下镜像不改变长度和角度大小。引导模式可提示按 Δ 的符号选择方向，探索模式允许镜像；空间验证仍用带符号的真实 Δ 显示方向。

## 6. 交互状态管理

建议状态机：

```text
INTRO
  → JUDGE_PROJECTION
  → CHOOSE_BASE
  → IDENTIFY_DELTA
  → DRAW_BASE
  → DRAW_HEIGHT
  → DRAW_HYPOTENUSE
  → INPUT_RESULT
  → VERIFY_SPACE
  → COMPLETE
```

每步只允许一个主动作：

- `JUDGE_PROJECTION`：选择答案；
- `CHOOSE_BASE`：选择一个投影面；
- `IDENTIFY_DELTA`：选择 Δx/Δy/Δz；
- `DRAW_*`：拖动或连接；
- `INPUT_RESULT`：输入/选择结果；
- `VERIFY_SPACE`：播放一次静态高亮或拖动空间端点观察关系。

状态迁移由 `transition(next, patch)` 统一完成；禁止 UI 直接修改多个阶段字段。

撤销策略：

- 当前拖动手势内可回滚到手势开始状态；
- 完成一个阶段后保留一次“上一步”；
- 构造错误不自动销毁用户输入；
- 切换构造面或重置时清空当前三角形，但保留 A/B 空间直线。

## 7. 正确性检查与反馈

### 7.1 构造校验

必须分别校验：

1. 底边是否等于所选投影长度；
2. 垂直边是否与底边成直角；
3. 垂直边长度是否等于对应坐标差绝对值；
4. 斜边是否连接正确的起终点；
5. 斜边长度是否等于实长；
6. 斜边与底边的夹角是否等于目标倾角；
7. 学生输入值与计算值是否在显示容差内。

构造校验输入应由独立的 `validateTriangleConstruction` 返回数据，不读取 Canvas 像素。

### 7.2 错误码

建议定义：

| 错误码 | 含义 | 首轮反馈 |
| --- | --- | --- |
| `LINE_DEGENERATE` | A、B 重合 | 提示两端点不能重合 |
| `PROJECTION_NOT_TRUE_LENGTH` | 把一般位置投影误认为实长 | 提示该投影小于实长 |
| `WRONG_BASE_PROJECTION` | 构造面与目标角度不一致 | 给出选择依据，不直接画答案 |
| `WRONG_DELTA_AXIS` | 选错坐标差 | 标出投影丢弃/保留的坐标 |
| `BASE_LENGTH_MISMATCH` | 底边长度错误 | 显示当前长度和理论长度 |
| `NOT_PERPENDICULAR` | 垂直边不垂直 | 显示当前角度 |
| `HEIGHT_LENGTH_MISMATCH` | 垂直边长度错误 | 显示目标差值 |
| `HYPOTENUSE_NOT_CLOSED` | 斜边未闭合 | 提示从哪个点到哪个点 |
| `RESULT_MISMATCH` | 数值结果错误 | 显示误差与显示精度 |
| `OUT_OF_VIEWPORT` | 构造超出画布 | 提示重置或缩小步长 |

反馈分级：

- 第 1 次错误：只说明“哪里不符合”；
- 第 2 次错误：增加一个几何关系提示；
- 第 3 次错误：高亮相关投影/坐标差；
- 自主模式可随时点“提示”，但不自动完成。

## 8. 几何实现建议

### 8.1 纯数学模块

建议 `triangle-metrics.js` 暴露：

```js
computeLineMetrics(a, b)
classifyLine(metrics)
buildConstructionTarget(metrics, projection)
angleDegrees(radians)
formatMetric(value, digits)
```

所有函数不读取 `this`、Canvas、`wx` 或 DOM。

### 8.2 构造目标

`buildConstructionTarget(metrics, projection)` 返回：

```js
{
  projection: 'H',
  baseLength: lH,
  orthogonalLength: Math.abs(dz),
  trueLength: L,
  angleRadians: alphaRadians,
  deltaAxis: 'z'
}
```

它是校验目标，不是直接绘制答案。UI 只在学生失败或完成后决定是否显示完整目标。

### 8.3 屏幕换算

建议新增加：

```js
screenToModelPrecise(screenDistance, unit, step, min, max)
modelToScreenDistance(modelDistance, unit)
```

默认 `step=0.1`，使用 `Math.round(value/step)*step`，并在写入前检查有限值。该函数放在新页面布局模块中，不修改现有 `math-utils.screenToModel`。

### 8.4 空间验证

空间验证只使用同一组 `A/B`：

- 绘制空间直线；
- 绘制三个投影；
- 高亮所选投影和缺失坐标差；
- 可选显示从投影点到空间点的投射线；
- 不高亮“自动完成的三角形”，避免答案泄露。

完成后可一次性显示“投影边 → 垂直边 → 实长”的分解动画。动画状态由时间参数计算，不从上一帧累加。

| T7 | 测试与冻结回归 | 新测试脚本、现有 `run-all` | 纯数学、交互、手机/PAD、首页四条底线通过 |

粗略工作量：**5–8 人日**，不含教学内容重新编写、真机等待和用户确认时间。

## 14. 需要用户确认的事项

以下不阻塞技术设计，但会影响实现口径：

1. **入口位置**：是否接受在首页“直线”模式内增加“知识点 · 求实长”入口，仅此一处触及 F1。
2. **镜像三角形**：是否允许直角三角形向上或向下镜像；建议允许，因为题目按绝对值计算 0°–90° 倾角。
3. **引导模式默认投影面**：建议默认 H 面，仍允许切换 V/W。
4. **学习事件粒度**：首版建议只记录章节进入/退出和模式完成，不把所有点击步骤写入云端。
5. **内容版本**：题目是否固定 `A(2,2,6)/B(6,5,2)`，还是同时允许拖动和随机生成；建议同时保留固定样板和受控随机。

## 15. 最终建议

第一阶段技术路线成立，建议按以下顺序推进：

1. 先实现并锁定纯数学模块与数值测试；
2. 再建立独立页面和单 Canvas 布局；
3. 完成自主探索模式；
4. 增加引导状态机与分级反馈；
5. 最后才加入首页入口和会话标签；
6. 不修改视图公式、不重算三投影、不新增后端和数据库。

核心成功标准不是“能显示三角形”，而是学生必须亲自完成投影选择、坐标差识别、垂直边构造和斜边连接，并能在空间模型中解释结果为什么成立。
