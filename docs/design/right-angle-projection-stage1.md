## 2. 教学关系

定理文字：

> **定理 I：** 垂直相交的两直线，其中有一条直线平行于一投影面时，则两直线在该投影面的投影仍反映直角。  
> **定理 II（逆）：** 相交两直线在同一投影面的投影成直角，且有一条直线平行于该投影面，则空间两直线的夹角必是直角。

页面固定包含：

- 灰色直线 `l`：位于投影面内，为不可拖动的投影面平行线。
- 橙色空间直线 `m`：具有面内和法向分量，为可拖动的一般位置直线；其正、水平、侧面投影继续使用红、绿、蓝。
- 默认构型中两线在 P 点相交并保持空间垂直；拖动端点后允许 m 偏离垂直方向，用于展示反例。
- 下方正、俯、左三面投影同时显示两条直线；三个视图中的 C、D 端点均可拖动，每次只改变当前端点。

## 3. 几何真值

纯数学实现位于 `pages/right-angle-projection/right-angle-model.js`。

每种平行线类型都声明：

- 所在投影面与对应二维视图；
- 面内方向 `u`（至少两个坐标分量非零，故不是投射线）；
- 投影面单位法向量 `n`。

计算 `q = normalize(n × u)`，得到面内与 `u` 垂直的方向。

构型：

```text
l 方向 = u
A = O - 3.6u
B = O + 3.6u
初始 m 方向 = normalize(3q + 1.6n)
C = P + c·m方向，c ∈ [1.2, 3.8]
D = P - d·m方向，d ∈ [1.2, 3.8]
```

因 `u · n = 0`，所以 `l ∥ P`；同时

```text
u · normalize(3q + 1.6n) = 0
```

初始构型精确满足 `u · m方向 = 0`。拖动 C 或 D 时，另一端点保持原坐标，
m 由新的两个实际端点确定，因此可以偏离 l 的垂直方向。
当 m 与 l 的夹角距 90° 不足 2° 时，拖动端点会吸附到精确垂面，便于稳定触发定理高亮；
离开吸附区后保留真实非垂直方向。两条直线是否相交由空间最短距离判定，页面显示“相交”或“异面”。

所有空间点 A、B、C、D、P 都位于 0..8 教学范围，三面投影由同一组点通过固定映射派生。

## 4. 页面结构

- 顶部页签只显示 α、β、γ 三个符号，水平线/正平线/侧平线名称仅保留为无障碍标签；三个按钮直接排列在页面底色上，使用白底细边和单一选中边框，不再设置外层卡片或灰色托盘。
- 页面专用画布高度在手机竖屏为 `460px`、宽屏为 `420px`；竖屏通过页面专属 `getLayout()` 将黑色空间区压缩为画布高度的 40%，其余高度留给三视图。
- Canvas 上层显示深色三维投影面和两条空间直线。
- 三维空间使用独立的满框屏幕比例：Z 轴顶端和 H 面最低角点均保留 2px 安全边距，`Z` 标签放在轴线右侧；放大只作用于空间视图，不改三视图投影单位。
- 三维空间中的两条直线都同时向 V/H/W 三个投影面投影；当前平行线所在面保留完整投影点标签，另外两面以同色细实线显示投影。空间画布不显示“水平线 l / 一般位置线 m”等线名文字。
- Canvas 下层显示三个投影面的二维结果、对应投影的实测夹角和可拖动的 C、D 点。
- 三视图沿用首页直线页的投影映射、端点标注和红、绿、蓝配色；A/B/C/D/P 五点常驻显示长对正、高平齐、宽相等对应辅助线。
- m 与 l 在空间中垂直时，l、m 同时加亮，三维交点绘制空间直角标记，并显示“空间垂直 → 投影出现直角”的状态；对应二维投影继续显示直角符号。
- 不满足空间垂直时，m 与其投影灰显且不显示直角；端点标注和投影对应线始终保留。
- 结果卡提供实时定理验证：显示 m 与对应投影面的夹角、l 是否平行、m 是否垂直 l、投影是否保持直角，并以绿/红状态提示条件是否满足。
- 底部用单个“直角投影定理”框格直接列出定理 I 与定理 II（逆），不再增加子标题或独立小框。

## 5. 当前边界

- 不修改首页点、线、面、三视图、立体或截交逻辑；仅把预留入口改为导航。
- 不新增云函数 action、数据库集合或字段。
- 当前只允许拖动一般位置线的 C、D 两端；A/B 为灰色投影面平行线的固定端点，P 为两线交点。
- 拖动触点先钳制在二维投影面板内部；被拖动的空间端点再钳制在 `0.8..7.2` 教学范围内，另一端点保持不动并沿用已有的范围内坐标。
- 学习会话沿用现有 `session.start`、`record.event`、`session.end`。
