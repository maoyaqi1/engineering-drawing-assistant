## 1. 项目是什么

「工程制图学习助手」是面向大学**画法几何与工程制图**课程的互动教学平台，由**三条并行的交付线**组成：

1. **微信小程序（学生端，主体）** —— 点/线/面互动、基本立体、平面切割立体、尺规作图练习、AI 教师答疑。
2. **微信云开发后端** —— `api` 云函数（学生端）、`teacher` 云函数（教师端）。
3. **网页教师后台** —— 静态页面，托管在 GitHub Pages，供教师查学情、管名册。

它**不是 CAD 系统**：所有能力都服务于空间认知、投影理解与几何构造过程的可视化。正确性、可解释性、交互反馈优先于功能数量。

## 4. 技术架构

### 小程序端
- 原生 WXML / WXSS / JavaScript，**无构建链、无包管理器**。
- 几何渲染：**Canvas 2D**（`canvas type="2d"`）。空间坐标是几何真值，三视图由同一份点模型派生。
- **不使用 Three.js / WebGL，不提供自由旋转相机**：三维区域是适合移动端的等轴测教学示意。

### 教师网页端
- 原生 HTML / CSS / JS。
- **不使用云 SDK**：通过腾讯云 CloudBase「HTTP 网关」以普通 HTTPS POST 调用 `teacher` 云函数。
- 网关地址写在 `teacher-web/js/config.js` 的 `gatewayUrl`：
  `https://cloud1-d4gwsysje82cf604a-1476352837.ap-shanghai.app.tcloudbase.com/teacher`
- 跨域需在 CloudBase 控制台「HTTP 网关 → 跨域设置」授权页面来源域名（已授权 `maoyaqi1.github.io`）。
- 身份校验：账号密码 → token，后续请求带 token；`UNAUTHORIZED` 时前端自动清会话回登录页。

### AI 教师
- 文本问答：DeepSeek（`deepseek-chat` 等）。
- 图片识图：阿里云百炼 **通义千问 Qwen-VL**（`qwen-vl-plus`），兼容模式接口。
- API Key **只存在于云函数环境变量**，绝不落到前端或仓库。
- **检索与视频定位**：千问侧服务（腾讯云 SCF 函数 URL），由云函数 `api` 在服务端调用；**回答生成仍在本仓库**（既定教学口径 + 16 篇知识库 + 服务回传的检索片段）。接口与决策见 `docs/AI教师对接契约.md`。
- **拍照提问每日限额 2 次**（2026-09-25 起）：视觉调用远比文字贵，按学生账号限次；**测试 / 内部账号不限次**。计数以服务端 `learning_records` 的 `ai_photo_ask` 事件为唯一依据（客户端计数不可信），超额时**不再触发视觉调用**。需要整体关停时，云函数环境变量 `AI_IMAGE=off`。
- **建议观看的视频**：回答气泡下方的卡片；受云函数环境变量 `VIDEO_PLAYBACK` 控制（置 `off` 可一键回滚到"只显示标题与时间点"）。

## 5. 部署链路（三处，务必分清）

| 产物 | 更新方式 | 注意事项 |
| --- | --- | --- |
| 小程序 | 微信开发者工具「编译」→ 预览 / 上传体验版 | — |
| `cloudfunctions/api` | 右键云函数 → **上传并部署：云端安装依赖** | 见下方注意事项 |
| `cloudfunctions/teacher` | 同上 | 同上 |
| 教师网页 | 把 `teacher-web/` 的 `index.html`、`css/`、`js/` 同步到预览仓库 | 见下 |

**云函数部署注意事项（踩过的坑）**
- 必须选「**云端安装依赖（不上传 node_modules）**」。
- 选「上传并部署：所有文件」会导致云端缺依赖，报 `FUNCTIONS_INVOCATION_FAILED`。
- 偶发 `ResourceInUse.FunctionName` 时，重新选「云端安装依赖」再传一次即可。
- **改了云函数不部署 = 前端调用报「未知操作」**，这是最常见的“功能没生效”原因。

**教师网页发布**
1. 源码在私有主仓库 `maoyaqi1/engineering-drawing-assistant`（分支 `master`）。
2. 发布走公开预览仓库 `maoyaqi1/hfjh-teacher-preview`，**分支是 `main`（不是 master）**。
3. 本地工作副本：`%TEMP%\hfjh-teacher-preview`（git clone）。同步方式：把 `G:\HFJH\teacher-web\` 的 `index.html`、`css/`、`js/`、`README.md` 覆盖过去 → `git add -A` → `git commit` → `git push origin main`。
4. GitHub Pages 会自动重建，约 1 分钟后刷新预览地址；页面无变化时用 `Ctrl+F5` 强刷清缓存。

**预览地址**：https://maoyaqi1.github.io/hfjh-teacher-preview/

**网络提示**：本机直连 GitHub 时通时不通（已清除所有 git 代理配置）。`Connection was reset` / `Could not connect to server` 属常态，**重试即可**，本地提交不会丢。

## 6. 权限与身份模型

| 角色 | 能做什么 |
| --- | --- |
| 超级管理员 | 查看**全部**学生、学习记录、AI 问答；新增/停用/重置密码/删除教师账号 |
| 普通教师 | 只能看**自己录入名册范围内**的学生及其学习数据（云函数按 `owner_teacher_id` 强制校验，不靠前端隐藏） |
| 学生 | 微信登录 + 自己填写学校/姓名/学号 |

**关键规则（改动时不得破坏）**
- 学生**都要**登录注册；**未在教师名册中的学生仍可正常使用互动工具，但不能使用 AI 教师提问**。
- 名册判重键 = **学号 + 姓名**（不同学校学号可能重复，不能只按学号判重）。
- 教师录入 / 批量导入 / 收编学生 → 自动写入 `roster` 开通 AI 权限；移除 → 撤销。
- 教师端「名册」(`students`) 与 AI 白名单 (`roster`) 由云函数联动，但与学生自主注册的 `users` 是两条独立路径。
