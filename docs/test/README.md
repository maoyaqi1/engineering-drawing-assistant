## 使用规则

1. 测试设计先查统一需求编号，再选择或更新测试用例。
2. 每次需求完成后同步更新相关测试用例和覆盖映射。
3. 实际验证结果写入单独的 `TEST-YYYYMMDD-<范围>.md`，不得把未执行用例标记为通过。
4. 历史 [TEST-001.md](./TEST-001.md) 与 [TEST-002.md](./TEST-002.md) 保留原结论，不作为当前用例基线。
5. `node scripts/test-case-coverage-check.cjs` 用于确认需求编号是否至少映射到一个测试用例。

测试用例描述“应该怎样验证”，测试报告记录“某次实际执行结果”，两者不得混为一份文档。
