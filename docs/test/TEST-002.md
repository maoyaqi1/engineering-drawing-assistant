## 5. 预期结果

预期结果一律取自 REQ-002 §11（表中 R1–R22）与 §20（异常与边界），本报告不自行改写。要点：

1. 权限：普通教师仅能看/管自己的班级；超管可见全部并可管理，但成员范围仍限于该班负责教师名册；越权一律 403（服务端强制）。

3. 交互：列表默认仅显示进行中的班级；已停用班级可查看但不可增删成员；添加学生部分成功时必须分别显示成功与失败明细。
