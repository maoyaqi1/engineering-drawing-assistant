## 2. 模拟器启动步骤

1. 打开 Windows“开始”菜单中的“微信开发者工具”。
2. 选择项目 `G:\HFJH`；如未出现在最近项目，使用“导入项目”并选择该目录。
3. 确认 AppID 使用项目 `project.config.json` 中的 `wx503b68d25311e803`。
4. 点击“编译”，不要先点击“上传”。
5. 模拟器机型先使用 iPhone 6/7/8 或 375×667 等价尺寸。
6. 打开调试器 Console，测试期间保持可见。
7. 先执行 A 登录与注册，再依次执行 B、C、D、E。
