## 7. Bug 清单

### BUG-20261024-01：小程序预览包超过 2MB

- 严重程度：**P0**
- 关联用例：`TC-SYS-07`、`TC-DATA-07`
- 现象：`cli preview` 进入上传阶段后返回错误码 `80051`，源码包 `2743KB`，超过 `2048KB`。
- 复现：登录微信开发者工具，执行 `cli.bat preview --project G:\HFJH`。
- 期望：生成预览二维码并允许真机扫码。
- 证据：CLI 报错原文 `source size 2743KB exceed max limit 2MB`。
- **已确认原因**：
  1. 只复制小程序运行文件（`app.*`、`pages/`、`images/`、`utils/`、`cloudfunctions/`）到临时项目，预览成功，包体 **237.8KB**。
  2. 在相同临时项目加入 `软著材料/`、`论文材料/`、`专利材料/` 后，复现同一失败，包体仍为 **2743KB**。
  3. `project.config.json` 的 `packOptions.ignore` 没有这三个顶层资料目录。
- **结论**：超限来自非运行研究资料被微信打包器计入源码包，不是 `pages/`、`utils/` 或云函数业务代码膨胀。
- 修复状态：**已修复**。`project.config.json` 已保留三类材料的打包排除规则，实际目录已移至仓库外的 `G:\HFJH_资料文档`；`.gitignore` 同时禁止其重新进入 Git。复测预览成功，包体降至 `237.8KB` 并生成二维码。

### BUG-20261024-02：浏览器版切割模块切换异常

- 严重程度：**P1**
- 关联用例：`TC-SYS-03`
- 现象：浏览器选择“平面切割立体”后，下拉值为 `3`，文档标题变为“基本立体”，内容仍停留在旧模块且所有模块面板隐藏。
- 控制台错误：`TypeError: Cannot read properties of undefined (reading 'introTitle')`，位置 `web/runtime.js:139`。
- 复现：启动 `web/index.html`，将教学模块切换到“平面切割立体”。
- **已确认原因链**：
  1. `web/index.html` 只有 4 个模块选项，索引 `3` 的文本是“平面切割立体”。
  2. DOM `change` 事件把数字 `3` 直接交给共享 `handleModulePicker`。
  3. `pages/index/ui-handlers.js` 按 5 个模式解释索引，`3` 对应 `solid`，而切割模式实际使用索引 `4`。
  4. `web/runtime.js` 的 `modeContent` 没有 `solid` 配置，随后在 `renderInterface()` 中以 `undefined.introTitle` 访问文案并抛错。
  5. 抛错前所有模块面板已先被隐藏，因此留下空面板和无响应的界面。
- 修复状态：**已修复**。浏览器选项改为语义值 `point / line / plane / section`，适配层显式映射切割模式到共享索引 `4`，并增加未知模式保护与静态接线检查。
