# 版本冻结记录 v1.4.0

> 版本号：`v1.4.0`  
> 冻结日期：2026-11-02  
> 上游版本：`v1.3.0`（提交 `4cc676b`）  
> 冻结性质：源码版本；云函数部署、小程序审核和线上发布状态单独记录

## 1. 版本定位

`v1.4.0` 在 `v1.3.0` 基础上增加两个学生端知识点页面，并完成画布界面的紧凑布局优化：

- 直角三角形法：切换投影面倾角，显示空间直角三角形、实长和坐标差，支持投影端点拖动；
- 直角投影定理：切换 α/β/γ 投影面平行线，联动三面投影，实时验证空间垂直与投影直角；
- 首页点、直线、平面、基本立体、平面切割立体统一使用紧凑画布；
- 投影体系页保持第一分角、八分角和展开交互，同时压缩黑底与展开图的纵向空白。

## 2. 发布范围

纳入本版本：

- `app.json` 注册知识点页面；
- `pages/index/` 的首页入口和五模式紧凑画布布局；
- `pages/projection/` 的紧凑画布与展开图轴线适配；
- `pages/triangle-method/` 全部页面源码；
- `pages/right-angle-projection/` 全部页面源码；
- 对应设计说明、页面冻结记录、布局检查和专项检查；
- `README.md` 的 v1.4.0 功能与版本说明。

不纳入本版本：

- 工作区中尚未提交的 AI、云函数、教师后台等其他批次；
- `web-release/`、`screen/` 等默认不纳入版本控制的本地产物；
- 任何密钥、密码或 Token。

## 5. 冻结约束

1. 后续修改应从 `v1.4.0` 建立可追溯差异。
2. 修改直角三角形法、直角投影定理或紧凑画布时，必须重跑对应专项检查、布局检查和全量本地检查。
3. 修改冻结源码须由用户明确要求，并说明可复现问题或具体产品需求。
4. 新增页面或交互仍需遵守 Canvas 2D、原生小程序和几何真值分层边界。
