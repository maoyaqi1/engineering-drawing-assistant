# 教师端管理后台（Web 版）

这是「工程制图学习助手」的教师端 Web 后台，静态托管在 GitHub Pages：
`https://maoyaqi1.github.io/hfjh-teacher-preview/`

## 已有功能

- 账号 + 密码登录（超级管理员账号由 `teacher` 云函数环境变量初始化，不在代码或文档中保存明文密码）
- 教学驾驶舱：学生总数 / 今日活跃 / 点线面今日 / AI 提问今日 + 名册人数 / 已注册 / 未注册 / 近 7 天 AI 提问 + 近 7 天趋势 + 班级概况 + 学情提醒 + 本周 AI 提问热点
- 学生管理：名册（教师录入）与未入册（自主注册）两个视图，新增 / 编辑 / 移除 / 批量导入（CSV 模板 + 校验预览）/ 收编；判重键为「学号 + 姓名」
- 学生详情：基本信息 + 累计时长 / 学习次数 / AI 提问 / 学习事件 4 个统计卡 + 章节进度 + 学习轨迹 + AI 问答 + **教师备注**（增删，仅教师端可见）
- 学习记录：教师可见范围内的全量学习行为事件流，可按姓名 / 学号、班级、行为类型筛选
- AI 教师分析：今日 / 近 7 天 / 累计提问统计、近 7 天高频知识点、问答明细（可展开）
- 教师管理（仅超管）：新增 / 停用 / 重置密码 / 删除教师账号
- 点线面分析与设置仍为占位（后续阶段实现）

## 权限模型

- 超级管理员：可见全部学生、全部学习记录与全部 AI 问答，可维护教师账号。
- 普通教师：只能看到自己录入名册范围内的学生及其学习数据（云函数按 `owner_teacher_id` 强制校验）。
- 未入册学生（自主注册、不在名册中）仍可使用互动工具，但不能使用 AI 教师；超管可在「未入册学生」中查看其学习数据。

## 技术

- 原生 HTML / CSS / JS，无构建、无框架。
- 通过腾讯云 CloudBase「HTTP 网关」以普通 HTTPS POST 调用 `teacher` 云函数（不使用云 SDK，不依赖云端登录态）。
  网关地址写在 `js/config.js` 的 `gatewayUrl`；跨域需在「HTTP 网关 → 跨域设置」中授权页面来源域名。
- 与小程序共用一个云环境，与学生端 `api` 云函数隔离。

## 部署步骤

1. 部署 `cloudfunctions/teacher`（微信开发者工具 → 右键云函数 → 上传并部署：**云端安装依赖**）。
2. 在 CloudBase 控制台确认「HTTP 网关」路由 `/teacher` 指向 `teacher` 云函数，且跨域已授权页面来源域名。
3. 把本目录内容（`index.html`、`css/`、`js/`）同步到预览仓库 `maoyaqi1/hfjh-teacher-preview` 的 `master` 分支，GitHub Pages 会自动更新。
4. 用已配置的超级管理员账号（见下方环境变量）登录。
5. 首次访问若提示「无法连接服务器」，先点登录页底部的「确认访问」打开网关地址（页面出现 JSON 提示即可），再回来登录。

## 需要先准备

- 一个已备案的自定义域名。
- `teacher` 云函数已部署，并在云函数配置中设置以下环境变量（值仅在云开发控制台填写，不写入仓库）：
  - `TEACHER_USERNAME=<通过环境变量配置>`
  - `TEACHER_PASSWORD=<通过环境变量配置>`
