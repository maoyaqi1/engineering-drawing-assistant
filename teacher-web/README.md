# 教师端管理后台（Web 版）

这是「工程制图学习助手」的教师端 Web 后台，通过微信云开发静态网站托管提供。**注意：需绑定「自定义域名」才能访达**——云开发对静态网站「默认域名」（`*.tcloudbaseapp.com`）有浏览器访问风控，直接访问会 418；绑定已备案的自定义域名后即可正常使用。

## 已有功能

- 账号 + 密码登录（超级管理员账号由 `teacher` 云函数环境变量初始化，不在代码或文档中保存明文密码）
- 教学驾驶舱：学生总数 / 今日活跃 / 点线面今日 / AI 提问今日 + 近 7 天趋势图
- 教师管理（仅超管）：新增 / 停用 / 重置密码 / 删除教师账号
- 学生、点线面、AI 教师、设置为占位（后续阶段实现）

## 技术

- 原生 HTML / CSS / JS，无构建、无框架。
- 通过 `@cloudbase/js-sdk`（`window.cloudbase`）调用 `teacher` 云函数。
- 与小程序共用一个云环境（`cloud1-4dgwsysje82c1c604a`），与学生端 `api` 云函数隔离。

## 部署步骤（申请到已备案域名后）

1. 在云开发控制台为静态网站托管**绑定自定义域名**（网站配置 → 域名配置 → 添加域名，需已在腾讯云备案）。
2. 把本目录内容上传到静态网站根目录（`index.html`、`css/`、`js/`）。
3. 用 `https://你的域名/` 访问。
4. 用已配置的超级管理员账号（见下方环境变量）登录。

## 需要先准备

- 一个已备案的自定义域名。
- `teacher` 云函数已部署，并在云函数配置中设置以下环境变量（值仅在云开发控制台填写，不写入仓库）：
  - `TEACHER_USERNAME=<通过环境变量配置>`
  - `TEACHER_PASSWORD=<通过环境变量配置>`
