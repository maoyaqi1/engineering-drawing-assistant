# 基本立体的投影与表面取点

## 知识点ID

G05

## 基本概念

立体是由内、外表面确定的实体。立体的投影，实质上是构成该立体的所有表面的投影总和。按立体表面的几何性质分为**平面立体**和**曲面立体**；按复杂程度分为**基本立体**和**组合体**。

- **平面立体**：由若干个平面图形围成的几何体，如棱柱、棱锥等。平面立体侧表面的交线称为棱线。若所有棱线互相平行，称为棱柱；若所有棱线交于一点，称为棱锥。
- **曲面立体（回转体）**：表面主要由回转曲面构成，如圆柱、圆锥、圆球、圆环等。

## 核心规律

画立体的投影，关键是画出立体的轮廓（转向轮廓线），并区分可见与不可见部分：

- 各表面的投影总和构成立体的投影；
- 立体的投影中，可见棱线、可见轮廓画粗实线，不可见部分画虚线；
- 曲面立体的投影要画出转向轮廓线（如圆柱的最左、最右、最前、最后素线），它是区分可见与不可见表面的分界线。

**常见平面立体**：棱柱（正六棱柱、三棱柱等）、棱锥（三棱锥等）。画图时先确定底面和棱线，再画出各投影。

**常见回转体**：

- **圆柱**：由圆柱面和上、下底圆围成，轴线垂直于某投影面时，在该投影面上投影为圆，另两面为矩形（矩形宽度等于直径）。
- **圆锥**：由圆锥面和底圆围成，投影为一个圆（底圆）和两个等腰三角形（锥面），锥顶为一点。
- **圆球**：三个投影都是直径等于球径的圆。
- **圆环**：由圆环面围成，投影反映内、外轮廓的圆。

## 空间意义

立体投影是“点、线、面”投影知识的综合应用。掌握常见立体的投影特征，是学习组合体视图、表面截交线和相贯线的基础。表面取点则是把“面”上的位置准确映射到三视图上的基本技能。

## 表面取点

在立体表面取点，要利用表面投影的积聚性或辅助线：

- **利用积聚性**：当表面在某投影面上积聚为直线或圆时，可直接在该投影面上确定点的投影，再由点的投影规律求出另外投影。
- **辅助线法（素线法/纬圆法）**：对圆柱、圆锥等回转体，过已知点作素线或纬圆，求出素线或纬圆的投影，点即在其中。

例如：六棱柱、三棱柱、三棱锥表面取点，可先确定点所在表面的投影，再利用积聚性或定比性求其他投影；圆柱、圆锥、圆球、圆环表面取点，用素线法或纬圆法。

## 作图方法

1. 先画出立体的对称中心（轴线、对称面）。
2. 画出底面或端面的投影。
3. 画出棱线或转向轮廓线的投影。
4. 判断可见性：位于观察者与投影面之间且朝向投影面的表面可见，反之为不可见。
5. 表面取点时，先判断点所在面，利用积聚性或作辅助线求出其余投影，并判断可见性。

## 典型问题

- 什么是平面立体？棱柱与棱锥有何区别？
- 常见回转体（圆柱、圆锥、圆球、圆环）的投影各有什么特征？
- 圆柱的转向轮廓线指的是什么？有何作用？
- 如何在棱柱/棱锥/圆柱/圆锥表面取点？
