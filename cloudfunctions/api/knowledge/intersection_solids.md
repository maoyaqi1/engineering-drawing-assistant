# 两立体相交、相贯线

## 知识点ID

G15

## 基本概念

两立体相交，其表面的交线称为**相贯线**。相贯线也是两个立体表面的共有线。求相贯线的实质，是求出两立体表面上的一系列共有点，然后依次光滑相连，并判断可见性、描深。

## 相贯线性质

1. 相贯线是两个立体表面的共有线；
2. 相贯线一般是封闭的线。

## 求相贯线的方法

- **利用积聚性投影**：当一个立体（如圆柱）的某投影积聚为圆时，可借助积聚性直接求点；
- **线面交点法（含素线法）**：求棱线（素线）对另一立体的贯穿点；
- **交线法（含辅助平面法）**：作辅助平面与两立体相交，求两组截交线的交点；
- **辅助球面法**：适用于两回转体共轴或球心重合的场合。

## 求相贯线的步骤

找点 → 连接点 → 判别可见性 → 整理轮廓线。

**判别可见性**：只有位于两形体都可见的侧面上的交线才可见；只要有一个侧面不可见，则该面上的交线不可见。

## 两平面立体相贯

两平面立体的相贯线通常是一条或几条闭合的空间折线或平面多边形。求法的实质是求两个立体的相交棱面的交线，或求一个立体的棱线与另一个立体的贯穿点。实体和虚体相交，也可看作虚体的多个平面截切实体、在实体表面形成切口，用求截交线的方法求解。

## 平面立体与曲面立体相贯

相贯线一般是封闭的空间折线，其中若干边是平面曲线或直线。每一部分平面曲线，可视为曲面立体表面被平面立体上某一表面所截的交线；两部分曲线的交点（结合点），是平面立体的棱线对曲面立体表面的贯穿点。因此可归结为求截交线和贯穿点的问题。

作图方法：先求棱面与曲面体的截交线，再求棱线的贯穿点；作图时先找特殊点，再补充中间点。

## 两曲面立体相贯

两曲面立体的相贯线为封闭的空间曲线。由于相贯线上的点既在甲立体表面又在乙立体表面，求相贯线就是求两立体表面的一系列共有点，再光滑连接、判可见性、描深。

## 空间意义

相贯线是工程形体（如管道接头、支架等）最常见的交线形式。掌握相贯线的性质、求法与可见性判断，能正确画出复杂组合体的三视图，是组合体与零件图表达的重要基础。相贯线作图常可借助“可预见性”先判断形状再逐步求点。

## 作图方法

1. 判断相贯线大致形状：根据两立体的类型及相对位置，预判是空间折线、平面曲线还是空间曲线。
2. 求特殊点：转向轮廓线上的点、最高/最低/最左/最右点、结合点等。
3. 补中间点：用辅助平面法、素线法或积聚性求点。
4. 光滑连接：按可见性分成可见段与不可见段。
5. 判断可见性并描深：两立体表面都可见段画粗实线，否则画虚线。
