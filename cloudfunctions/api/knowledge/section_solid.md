# 平面与立体相交、直线与立体相交、截交线

## 知识点ID

G07

## 基本概念

**截交线**：截平面与立体表面的交线。当立体被截平面切割后，截平面与立体表面的交线称为截交线，它围成的平面图形称为截面（断面）。

求截交线的实质，是求出截平面与立体表面的共有点，再依次连接并判断可见性。

## 核心规律

平面与曲面立体截交线的性质：

- 截交线是截平面与曲面立体表面的共有线；
- 截交线的形状取决于曲面立体的形状，以及截平面与曲面立体轴线的相对位置；
- 截交线都是封闭的平面图形。

## 求平面与平面立体的截交线

平面与棱锥、棱柱的截交线是封闭的平面多边形。步骤：

1. 找到截平面与立体上若干条棱线的交点；若立体被多个平面截切，还应求出截平面之间的交点。
2. 依次连接各点。
3. 判断可见性。
4. 整理轮廓线。

## 求平面与曲面立体的截交线

一般步骤：先作**空间及投影分析**（分析回转体形状以及截平面与轴线的相对位置，确定截交线形状；分析截平面与投影面的相对位置，明确投影特性如积聚性、类似性），再**画出截交线的投影**：

- 截交线投影为非圆曲线时，先找特殊点，再补充中间点；
- 将各点光滑连接，并判断可见性。

**平面与圆柱相交**：截平面垂直于圆柱轴线时截交线为圆；倾斜时为椭圆；平行于轴线时为两条素线（矩形）。

**平面与圆锥相交**：求截交线上的点常用**纬圆法**和**素线法**。具体形状取决于截平面与圆锥轴线的相对位置，可能是圆、椭圆、抛物线式曲线、双曲线式曲线或两条素线。

**平面截圆球**：截交线为圆。求圆球截交线上的点用**纬圆法**（在圆球表面上取若干个纬圆，求出这些纬圆与截平面的交点）。

## 直线与立体相交（贯穿点）

直线与立体相交，是直线从立体一侧表面贯入、另一侧表面穿出，其交点一般成对出现，称为**贯穿点**。求贯穿点的实质是求直线与平面或直线与曲面的交点问题。

- 若立体表面的投影有积聚性，可直接利用积聚性求出交点；
- 对于投影没有积聚性的表面，用“三步骤”求交点：
  1. 过直线作适当的辅助平面；
  2. 求出该辅助平面与立体表面的交线；
  3. 求出交线与直线的交点。

## 空间意义

截交线是“平面切割立体”问题（平面切割体的三视图）的核心。掌握截交线的形状判断与作图，就能把曲面体截切后的三视图正确画出，并判断可见性。直线与立体的贯穿点则是更一般的位置问题，在相对位置与综合题中广泛应用。

## 作图方法

1. 判断截交线形状：先看立体类型，再看截平面与轴线的相对位置。
2. 确定已知投影：结合积聚性、类似性找出截交线的已知投影，求出未知投影。
3. 求点：先特殊点（最高、最低、最左、最右、最前、最后、轮廓线上的点），再补充中间点。
4. 连线与判可见性：光滑连线，位于可见表面的部分画粗实线，否则画虚线。
5. 整理立体轮廓，去掉被切掉部分的线。

## 典型问题

- 什么是截交线？它与相贯线有什么区别？
- 平面与圆柱、圆锥、圆球相交，截交线各可能是什么形状？
- 如何求平面与棱柱、棱锥的截交线？
- 什么是贯穿点？如何求直线与立体的贯穿点？
