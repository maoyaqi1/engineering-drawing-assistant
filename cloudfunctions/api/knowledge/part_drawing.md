# 零件图

## 知识点ID

G12

## 基本概念

零件图是制造和检验零件的主要依据，内容包括四部分：

1. **图形**：用一组视图（视图、剖视图、断面图等）完整、清晰、简洁地表达零件的结构形状。
2. **尺寸**：完整、清晰、合理地标注出零件结构形状及相对位置。
3. **技术要求**：用规定符号和文字给出制造、检验时应达到的要求（表面粗糙度、公差等）。
4. **标题栏**：填写零件名称、材料、比例、制图人与校核人、日期等。

## 零件构形设计

按功能要求（设计要求）和工艺要求，以及经济、美观等因素确定零件结构形状和尺寸。

- **功能结构（主要结构）**：起支撑、容纳、传动、连接、安装、密封等作用，大致分“工作部分、安装部分、连接部分”。
- **工艺结构（局部结构）**：为便于毛坯制造、加工、测量、装配而设计。铸造结构有**圆角、起模斜度、铸件壁厚**；机械加工结构有**倒角、退刀槽/砂轮越程槽、孔、凸台和沉孔**。
- 圆角和起模斜度会使形体交线不明显，形成的线称为**过渡线**，其画法与相贯线相同（按无圆角求相贯线，用细实线画到理论交点处）。

## 螺纹

螺纹是在圆柱（或圆锥）表面沿螺旋线有规定牙型的连续凸起。外螺纹在外表面，内螺纹在内表面。

**螺纹五要素**：牙型、直径、线数、螺距和导程、旋向。只有当内外螺纹五要素一致时才能正确旋合构成螺纹副。

- **牙型**：通过螺纹轴线剖面区域的轮廓形状，用特征代号表示。
- **直径**：有大径 d/D、中径 d2/D2、小径 d1/D1。公称直径代表螺纹尺寸（普通螺纹公称直径即大径）。
- **线数**：单线螺纹或多线螺纹。
- **螺距 p**：相邻两牙在中径线上对应点间的轴向距离；**导程 ph**：同一条螺旋线上相邻两牙对应点间轴向距离。单线时导程=螺距，多线时导程=螺距×线数。
- **旋向**：右旋 RH（标记中省略）、左旋 LH。

牙型、直径、螺距三要素都符合标准的称为标准螺纹；线数、旋向不特别注明为单线右旋。

**螺纹规定画法**：外螺纹大径画粗实线、小径画细实线；内螺纹相反；螺纹副旋合部分按外螺纹画，其余按各自画法。螺纹按规定画法画出后要注写标记。

## 零件表达方案

考虑便于看图、完整清晰、画图简便。方法：分析零件 → 选择主视图 → 选择其他视图和表示方法。

- **主视图投射方向**：应较多反映零件形状特征。
- **主视图位置**：尽量与零件工作位置（自然位置）或加工位置一致。

## 尺寸合理标注

标注尺寸的合理性要同时满足设计要求和工艺要求。**基准**是确定零件位置的面、线或点，分**设计基准**（反映设计要求）和**工艺基准**（便于加工测量），两者能统一最好，不能统一以保证设计要求为主。长、宽、高方向至少各有一个主要基准。

标注原则：

- **考虑设计要求**：功能尺寸直接注出；互相联系的尺寸必须注出；不要注成封闭尺寸链。
- **考虑工艺要求**：铸锻件按形体标注；毛面与加工面尺寸分开标注；便于测量；典型结构按规定标注。

## 零件图上的技术要求

零件图上通常标出：表面粗糙度、尺寸公差、形状与位置公差、材料及其热处理和表面处理。

- **表面粗糙度**：加工表面上较小间距和峰谷组成的微观几何特性，是衡量表面质量的指标，选用要满足功能又经济合理。
- **互换性**：相同零件不经挑选或修配即可装配并保持性能的性质。
- **尺寸公差**：尺寸允许的变动量。有关术语包括基本尺寸、实际尺寸、极限尺寸、上/下偏差（孔 ES/EI、轴 es/ei）。公差 = 最大极限尺寸 − 最小极限尺寸 = 上偏差 − 下偏差。公差等级分为 20 级（IT01、IT0、IT1~IT18），从 IT01 到 IT18 依次降低。基本偏差确定公差带相对零线位置。
- **配合**：基本尺寸相同的孔和轴公差带之间的关系，分间隙配合、过盈配合、过渡配合。基准制分**基孔制**（基准孔 H，下偏差为零）和**基轴制**（基准轴 h，上偏差为零）。
- **形状和位置公差**：形状公差（直线度、平面度、圆度、圆柱度等）；位置公差（平行度、垂直度、同轴度等）。公差带是限制实际形状或位置变动的区域。

## 看零件图的方法和步骤

看标题栏 → 分析表达方案（找主视图、其他视图、剖切面位置、投射方向）→ 结构分析（先大致轮廓再分部分，逐个看懂内外部结构）→ 尺寸分析（定形定位尺寸、基准、功能尺寸、总体尺寸）→ 工艺和技术要求分析。

## 零件测绘

零件测绘是对已有零件分析后用目测比例徒手画草图、测量并标注尺寸和技术要求，再整理成零件图的过程。测绘时应正确选择测量基准，磨损部位参考配合零件尺寸，配合尺寸精确测量并查手册给出偏差，非配合尺寸圆整为整数，细小标准结构查标准值，缺陷（缩孔、砂眼等）不画出。

## 空间意义

零件图是设计意图与制造实施的桥梁。理解零件图内容、表达方案、尺寸标注和技术要求，才能正确“读零件图、画零件图”，进而看懂机器。
