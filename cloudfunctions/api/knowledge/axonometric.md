# 轴测图

## 知识点ID

G16

## 基本概念

轴测图：用平行投影法把物体连同确定它的直角坐标系一起，沿不平行于任一坐标平面的方向投射到一个投影面上所得图形。它是一种单面投影图，能同时反映物体三个坐标面的形状，形象、逼真、富有立体感。

轴测图一般不能反映各表面实形，度量性差、作图较复杂，因此在工程上常作辅助图样。

- 用正投影法形成的叫**正轴测图**；用斜投影法形成的叫**斜轴测图**。
- 投影面 P 称轴测投影面，投射方向 S 称投射方向；空间坐标轴在轴测投影面的投影称**轴测轴**（OX、OY、OZ）。
- **轴间角**：轴测轴之间的夹角。
- **轴向伸缩系数**：轴测单位长度与空间坐标单位长度之比，用 p、q、r 表示（p=OA/O₀A₀ 等）。

## 投影特性

- 两线段平行，其轴测投影也平行；
- 两平行线段的轴测投影长度与空间长度比值相等；
- 凡与坐标轴平行的线段，可在轴测图上沿轴向进行度量和作图。

## 正等轴测图

正等轴测图的轴间角均为 120°，三个轴向伸缩系数相等。画法：

1. 在视图上建立坐标系；
2. 画出正等测轴测轴；
3. 按坐标关系画出物体的轴测图。

常用方法：

- **坐标法**：沿坐标轴量取线性尺寸，利用轴测轴定出各顶点轴测投影再连线；
- **切割法**：对不完整形体先按完整画出，再切割出不完整部分；
- **组合法**：先形体分析，分成若干基本形体，逐个画出再组合。

圆柱、圆台、圆球、圆环及一般回转面的正等轴测图，要按相应的近似画法（如用椭圆表示圆）画出。

## 斜二等轴测图

斜二测与正等测的主要区别在于轴间角和轴向伸缩系数不同，画图方法无本质区别。斜二测适合表达只有一个方向平面形状复杂、其他两个方向形状简单的物体。

## 轴测图的其他知识

- **轴测剖视图**：常采用两个平行于坐标面的相交平面剖切组合体的 1/4，以表达内外形状；剖面线画成等距、平行的细实线，方向随轴测轴和伸缩系数而不同。
- **轴测图尺寸标注**：线性尺寸一般沿轴测轴方向标注；角度尺寸线画成相应椭圆弧；圆的直径尺寸线和尺寸界线分别平行于圆所在平面内的轴测轴。
- **轴测图选择**：要求结构表达清晰、立体感强、作图简便。当与三个坐标面平行平面上都有圆时选用正等测；只有一个方向形状复杂时用斜二测。

## 空间意义

轴测图弥补正投影图立体感不足的缺点，常用于说明机器结构、安装和使用情况，也用于构思和想象物体形状。掌握轴测图画法有助于空间想象和读图。

## 作图方法

画组合体正等轴测图常用组合法：先分形体，按相对位置逐个画出，再擦去形体间不应有的线。圆的轴测投影用椭圆表示，可用近似画法（如四心椭圆法）作出。轴测草图要目测准轴测轴夹角（X、Y 轴与水平线成 30°），尽量使平行线相互平行。

## 典型问题

- 什么是轴测图？与正投影图相比有何特点？
- 正轴测图和斜轴测图有何区别？
- 正等轴测图的轴间角和轴向伸缩系数如何？
- 圆柱的正等轴测图中圆变成什么图形？如何画？
- 轴测剖视图的剖面线如何绘制？
