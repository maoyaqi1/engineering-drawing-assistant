# 直线与平面、平面与平面的相对位置

## 知识点ID

G08

## 基本概念

本章研究直线与平面、平面与平面之间的平行、相交、垂直关系，以及点、线、面的综合度量问题。若直线与平面、平面与平面不平行，则必相交。

- 直线与平面相交有**交点**，交点是直线与平面共有的点；
- 两平面相交有**交线**，交线是两平面共有的直线；
- 求交点和交线的实质，是求共有点、共有线的投影。

## 平行问题

**直线与平面平行**：若平面外的一条直线与平面内的一条直线平行，则该直线与该平面平行。

**两平面平行**：一个平面内的两相交直线，与另一个平面内的两相交直线对应平行，则此两平面平行。若两投影面垂直面相互平行，则它们具有积聚性的那组投影必相互平行。

## 相交问题

**特殊位置线面相交**：可借助直线或平面的积聚性投影直接求出交点。例如当平面某投影有积聚性、直线为一般位置时，交点的一个投影是直线与平面积聚性投影的交点，另一投影可在直线的另一投影上找到。

**一般位置线面相交（辅助平面法）**：因直线和平面都没有积聚性，用辅助平面法求交点：

1. 含已知直线作特殊位置辅助平面；
2. 求辅助平面与已知平面的交线；
3. 求交线与已知直线的交点，交点即为所求。

**两平面相交**：求两平面的交线，可看作求两个共有点的问题。特殊位置平面与一般位置平面相交时，交线可直接由积聚性投影求出；两个一般位置平面相交，则用求一般位置线面交点的方法找出交线上的两个点，连线即得交线。

**可见性**：利用重影点判断投影的可见性。

## 垂直问题

**直线与平面垂直**：垂直于平面的直线称为该平面的垂线或法线。几何条件：若一直线垂直于一平面，则它必垂直于属于该平面的一切直线。

**定理 1**：若一直线垂直于一平面，则直线的水平投影必垂直于属于该平面的水平线的水平投影；直线的正面投影必垂直于属于该平面的正平线的正面投影。

**定理 2（逆）**：若一直线的水平投影垂直于属于平面的水平线的水平投影，正面投影垂直于属于平面的正平线的正面投影，则直线必垂直于该平面。

**两平面垂直**：若一条直线垂直于一平面，则包含这条直线的所有平面都垂直于该平面。反之，两平面相互垂直，则由属于第一个平面的任意一点向第二个平面所作的垂线必属于第一个平面。

## 度量问题（综合题）

度量问题的核心是根据直角投影定理作平面的垂线或直线的垂面，并求其实长或实形。

**距离的度量**：

- 点到点：求两点间线段的实长；
- 点到直线：过点作平面垂直于直线，求垂足，再求点与垂足的线段实长；
- 点到平面：过点作平面的垂线，求垂足，再求点与垂足的线段实长；
- 平行直线间、交叉直线间、直线与平行平面间、两平行平面间的距离，都转化为“点到直线/平面”的距离来求。

**角度的度量**：

- 两相交直线夹角：任作一直线与两直线相交构成三角形，求出三角形实形得到夹角（直角三角形法）；
- 直线与平面夹角：直线和它在平面上的投影所夹的锐角。过直线上一点作平面的垂线，求直线与垂线的夹角的余角，即得直线与平面的夹角（余角法）；
- 两平面夹角：即二面角的平面角。在空间任取一点，分别作两平面的垂线，求两垂线夹角的补角（补角法）。

## 空间意义

直线与平面的相对位置是画法几何综合题的骨架。平行、相交、垂直的判断与作图，配合距离和角度的度量，可解决大量工程图示与图解问题，是学习截交与相贯之前的必备基础。

## 作图方法

1. 平行：利用“平面内一条直线平行已知直线”“两平面内对应相交直线平行”作判断与作图。
2. 相交：有积聚性用积聚性；无积聚性则用辅助平面法。
3. 垂直：利用垂线投影定理（水平投影⊥水平线、正面投影⊥正平线）作法和判断。
4. 度量：距离问题作垂线求垂足再求实长；角度问题用余角法或补角法。
