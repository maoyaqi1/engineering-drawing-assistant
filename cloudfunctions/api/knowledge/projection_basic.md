# 投影基本概念与正投影性质

## 知识点ID

G01

## 基本概念

投影法：用投射线将形体向选定的投影面进行投射，并在该投影面上得到形体投影的方法，称为投影法。它由投射中心、投射线、形体（被投射对象）和投影面等要素构成。

按投射线的性质，投影法分为两类：

- **中心投影法**：投射线均发自投射中心时，称为中心投影法。所得投影大小随形体到投射中心的距离而变化。
- **平行投影法**：投射线互相平行时，称为平行投影法。投射线垂直于投影面时称为**正投影法**；投射线倾斜于投影面时称为**斜投影法**。工程图样主要采用正投影法。

## 核心规律

正投影有四个基本性质：

- **真实性（度量性）**：当线段或平面图形平行于投影面时，其投影反映实长或实形。
- **积聚性**：当直线或平面垂直于投影面时，其投影积聚为一点或一条直线。
- **相似性（类似性）**：当直线或平面倾斜于投影面时，其投影仍为直线或边数相同的多边形，但长度或面积发生变化。
- **平行性**：空间相互平行的两直线，其同面投影仍相互平行；且平行线段之比等于其投影之比。

工程图样对投影应用的要求：

- **唯一性**：能确切、唯一地反映空间几何关系，使二维图形与三维实物一一对应。
- **度量性**：能根据二维图形方便地确定几何原型的形状与各部分结构尺寸。

## 空间意义

画法几何是几何学的一个分支，由法国学者蒙日（G. Monge，1746—1818）于 1795 年创立，1920 年引入我国。它用投影法研究图示和图解空间几何问题，为工程图学提供基本原理和基本方法。正投影的“真实性、积聚性、相似性、平行性”是理解三视图、判断投影特性和作图的基础。

## 作图方法

判断某投影是反映实形、积聚还是类似形，关键看该几何元素与投影面的相对位置：

- 平行于投影面 → 真实性（反映实长或实形）；
- 垂直于投影面 → 积聚性（积聚为点或线）；
- 倾斜于投影面 → 相似性（类似形，形状相似、大小变化）。
