# 机件的图样画法（视图、剖视图、断面图）

## 知识点ID

G11

## 基本概念

机件：组成机器的零件。图样画法的任务是完整、清晰地表达机件的结构形状。视图主要用于表达机件外部结构形状；剖视图和断面图用于表达内部结构。

## 视图

**视图**：机件向多面投影体系各投影面作正投影所得图形。分为基本视图、向视图、局部视图、斜视图。

- **基本视图**：机件放在由六个基本投影面构成的体系中，分别投射得主视图、俯视图、左视图、右视图、仰视图、后视图。按图示位置配置时不需标注名称；“三等”规律仍存在。
- **向视图**：未按投影关系配置的视图。
- **局部视图**：将机件某一部分向基本投影面投射所得视图。断裂边界用波浪线（或双折线）表示；当结构完整且外轮廓封闭时省略波浪线。
- **斜视图**：机件向不平行于基本投影面的平面投射所得视图。通常按投影关系配置，也可旋转后画出并加旋转符号。

## 剖视图

假想用剖切面（平面或柱面）剖开机件，移去观察者与剖切面之间的部分，将其余部分向投影面投射所得的图形称为剖视图。应注意：剖面区域要画剖面符号；剖切具有假想性（机件仍完整）；剖切面尽量通过较多内部结构的轴线或对称面；按要求标注剖切符号、箭头和名称。

剖切面种类：单一剖切面、几个平行的剖切平面、几个相交的剖切面。

剖视图分为：

- **全剖视图**：用剖切面完全剖开机件所得，用于表达不对称或外形简单的对称机件的内形。
- **半剖视图**：以对称中心线为界，一半画剖视、一半画视图，用于内外形都需表达的对称机件。
- **局部剖视图**：用剖切面局部剖开机件，剖与非剖分界用波浪线，用于表达局部内形（内外兼顾）。

## 断面图

假想用剖切面把机件某处切断，仅画出截断面的图形称为断面图，用于表达某部分截断面的形状。

- **移出断面图**：画在视图之外，轮廓线用粗实线，常配置在剖切线延长线上；剖切平面一般垂直于机件轮廓线。
- **重合断面图**：画在视图之内，轮廓线用细实线，用于截面形状简单且不影响图形清晰的情形。
- 剖面区域要画剖面符号；剖切平面通过回转面形成的孔或凹坑轴线时，应按剖视画出。

## 局部放大图与简化画法

- **局部放大图**：将机件部分结构用大于原图比例画出，尽量配置在被放大部位附近，上方标注放大比例。
- **简化画法**：在保证不致误解的前提下力求简洁。例如：均匀分布的孔、肋可旋转到剖切平面上画出；相同结构按规律分布时只画几个完整结构；相贯线、过渡线可用圆弧或直线代替；与投影面倾斜 ≤30° 的圆可用圆或圆弧画出。

## 空间意义

同一机件可用不同图样画法表达：外形用视图，内形用剖视，局部截面用断面。选用合适的画法，可做到“完整、清晰、简洁”地表达结构，是读图和画零件图、装配图的基础。

## 作图方法

画剖视图步骤：画视图底稿 → 确定剖切面位置、画剖面区域和剖面符号 → 画剖切后可见部分及必要细虚线 → 标注、描深。选择画法：对称机件内外形都要表达用半剖；不对称或外形简单用全剖；局部结构用局部剖。
