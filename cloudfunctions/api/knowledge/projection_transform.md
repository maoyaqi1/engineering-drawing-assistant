# 投影变换（换面法）

## 知识点ID

G14

## 基本概念

**换面法**：空间几何元素本身位置不动，用一个新的投影面（辅助投影面）代替原有的某一投影面，使空间几何元素相对新投影面处于解题所需的有利位置，然后将空间几何元素向新投影面投影的方法。

新投影体系的建立要遵循新投影面的选择原则：

1. 新投影面必须使空间几何元素处于有利解题的位置；
2. 新投影面必须垂直于原投影体系中的某一个投影面。

## 核心规律

**点的投影变换规律**：

1. 点的新投影和不变投影的连线，必垂直于新投影轴；
2. 点的新投影到新投影轴的距离，等于点的旧投影到旧投影轴的距离。

点的变换是可逆的，并且可以连续进行两次或多次变换。

## 直线的投影变换

- 将一般位置直线变为投影面平行线：新投影面平行于该直线，直线在新投影面上反映实长及对相应投影面的倾角；
- 将投影面平行线变为投影面垂直线：新投影面垂直于该直线，直线在新投影面上积聚为一点；
- 将一般位置直线变为投影面垂直线：需两次变换，先变为投影面平行线，再变为投影面垂直线。

## 平面的投影变换

- 将一般位置平面变为投影面垂直面：新投影面垂直于该平面内的一条投影面平行线，平面在新投影面上积聚为一条直线，从而反映该平面对相应投影面的倾角；
- 将投影面垂直面变为投影面平行面：新投影面平行于该平面，平面在新投影面上反映实形；
- 将一般位置平面变为投影面平行面：需两次变换，先变为投影面垂直面，再变为投影面平行面。

## 空间意义

换面法通过改变投影体系，使原本“倾斜”的几何元素变成“平行”或“垂直”，从而把一般位置的度量问题转化为特殊位置的简单问题，是求线段实长、平面实形及其对投影面倾角，以及解决一般空间几何元素定位与度量问题的重要手段。

## 作图方法

1. 确定解题目标：求实长/实形/倾角，还是求交点/位置。
2. 选择新投影面：使其垂直于原体系中的一个投影面，并使几何元素处于有利位置。
3. 按点的变换规律，逐个求出新投影：新投影与不变投影的连线垂直于新投影轴；新投影到新轴距离等于旧投影到旧轴距离。
4. 必要时进行第二次变换，直至得到所需结果。

## 典型问题

- 换面法的新投影面选择原则是什么？
- 点的投影变换规律有哪两条？
- 如何把一般位置直线变为投影面平行线、垂直线？
- 如何把一般位置平面变为投影面垂直面、平行面？
- 用换面法如何求平面图形的实形？
