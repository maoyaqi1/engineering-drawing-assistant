# 装配图

## 知识点ID

G06

## 基本概念

**装配图**：表达机器或部件的图样。它表达机器的工作原理、零件间的装配关系、零件的主要结构形状，以及装配、检验、安装时所需的尺寸数据和技术要求。

装配图与零件图的分工：零件图表达单个零件的结构形状、尺寸与技术要求，是制造零件的依据；装配图表达部件整体的工作原理与装配关系，是装配、检验、安装的依据。装配图由零件草图和装配示意图画出，再由装配图拆画零件图。

## 装配图的内容

一张完整的装配图包含四部分：

1. **一组图形**：表达机器的工作原理、零件间的装配关系和零件的主要结构形状。
2. **必要的尺寸**：性能（规格）尺寸、装配尺寸、外形尺寸、安装尺寸等。
3. **技术要求**：装配、检验、使用等方面的要求。
4. **零件序号、明细栏和标题栏**：对每个零件或部件都必须编注序号或代号，并填写明细栏，以便统计零件数量、进行生产准备；看图时也根据序号查阅明细栏，了解零件的名称、材料和数量。

## 装配图的规定画法

1. 两零件的**接触表面（或配合表面）**用一条轮廓线表示；**非接触表面**用两条轮廓线表示。
2. 同一零件的剖面线方向和间隔应一致；相邻两零件的剖面线要区分（改变方向或间隔）。
3. 对实心零件（如轴）和标准件（如螺栓、螺母），当剖切平面按纵向剖切、且通过其轴线或对称面时，这些零件按不剖处理，只画外形。

## 装配图的特殊表示法

拆卸画法、沿结合面剖切画法、单独表示某个零件、夸大画法（薄片零件与微小间隙可夸大画出）、假想画法（相邻零、部件用双点画线画出）、展开画法（把空间结构展开在平面上画出）、简化画法（工艺结构如圆角、倒角等可不画）。

## 装配图中的尺寸标注

装配图只标注进一步说明机器的性能、工作原理、装配关系和安装要求所必需的尺寸：

1. **性能尺寸（规格尺寸）**：说明机器或部件的性能、规格。
2. **装配尺寸**：包括配合尺寸——表示两零件之间的配合性质，由基本尺寸和孔、轴的公差带代号组成；以及相对位置尺寸——装配机器和拆画零件图时需保证的零件间相对位置尺寸。
3. **外形尺寸**：总长、总宽、总高。
4. **安装尺寸**：安装时所需的尺寸。
5. **其他重要尺寸**。

## 装配图中的技术要求

用文字说明图形无法表达清楚的内容：装配体的性能、安装、使用等要求；装配体的制造、检验等要求；装配体对润滑、密封等的特殊要求。

## 零件序号与明细栏

- 序号（或代号）注在图形轮廓线外边，写在指引线的横线上或圆内（指引线指向圆心），横线或圆用细实线画出。
- 指引线由所指零件的可见轮廓内引出（剖开时尽量由剖面区域内引出），末端画一小圆点；很薄的零件或涂黑的剖面不易画圆点时，可在指引线末端画出指向该部分轮廓的箭头。
- 指引线分布要均匀、不彼此相交、不过长；通过有剖面线的区域时不应与剖面线平行，必要时可画成折线，但只允许折弯一次；一组紧固件等装配关系清楚的零件组可采用公共指引线。
- 相同的零部件用一个序号，一般只标注一次；序号沿水平或铅垂方向按顺时针或逆时针次序排列整齐；序号字体比尺寸数字大一号或两号。
- **明细栏**是说明组成机器或部件的零部件的详细目录，一般由序号、名称、数量、材料、备注等组成；一般配置在标题栏上方，按由下而上的顺序填写，以便增加零件时向上画格；位置不够时可紧靠标题栏左边自下而上延续；也可按 A4 幅面作为装配图的续页单独绘出（此时从上到下填写，并在明细栏下方配置与装配图完全一致的标题栏）。明细栏和标题栏的格式在 GB/T 10609.2 中已有规定，教学中可采用简化的明细栏。

## 装配体构形设计的合理性

装配体设计要满足功能要求、加工工艺要求，还要具有一定的宜人性和审美性。常见结构问题：

- **接触面与配合面**：两零件的接触面在同一方向上只能有一对接触面，以保证接触良好、降低加工要求；接触面需经机械加工，合理减少加工面积可降低加工费用；具有不同方向接触面的两零件，在接触面交角处不应都做成尖角或半径相同的圆角。
- **轴向零件的固定**：为防止轴上零件产生轴向窜动，可用轴肩、弹性挡圈固定轴承内、外圈；用轴端挡圈固定内圈；用圆螺母及止动垫圈固定。
- **防松结构**：受振动或冲击时螺纹连接可能松动，常用双螺母锁紧、止动垫圈防松、双耳止动垫片锁紧等。
- **密封防漏结构**：防止内部液体外漏和外部灰尘、杂质侵入；滚动轴承既防外部灰尘和水分进入，又防润滑剂渗漏。
- 构形还要把尺度、比例、均衡、稳定、过渡、呼应等要素结合起来，力求和谐统一。

## 空间意义

装配图是设计意图与装配实施的桥梁：零件图解决“每个零件怎么做”，装配图解决“这些零件怎么装成一个部件”。掌握装配图的内容、规定画法与特殊表示法，才能正确画装配图、看装配图，并由装配图拆画零件图。

## 作图方法

**画装配图的步骤**：拟定表达方案 → 定方案、定比例、定图幅并画出图框 → 布图、画基准线 → 画图 → 标注尺寸 → 编零件序号、填写明细栏和标题栏 → 检查、描深。

拟定表达方案的要点：选择主视图，一般按部件的工作位置选择，并常通过装配线的轴线将部件剖开；再根据尚未表达清楚的装配关系、工作原理和零件结构确定其他视图。

**部件测绘的步骤**：① 对部件全面了解和分析——了解构造、功用、工作原理与使用情况，检测有关的技术性能指标和一些重要的装配尺寸；② 拆卸零件——制定拆卸顺序、分组编号放置，避免损坏零件，保证部件原有的完整性、精确性和密封性；③ 画装配示意图——边拆卸边补充、更正，记录各零件间的装配关系；④ 画零件草图——受时间与工作场地限制，徒手画出各零件草图。

## 看装配图的方法和步骤

1. **概括了解并分析视图**：阅读说明书、技术要求、标题栏，了解机器的性能和工作原理；阅读明细栏，对照零件序号了解零件数量、材料、规格；分析全图用了几个视图、每个视图采用什么表示法、视图间的投影关系以及各视图所表达的内容。
2. **深入分析部件的工作原理和装配关系**：从主视图入手，根据各装配干线对照零件的投影关系；由剖面线的不同分清零件轮廓范围；由配合代号了解零件间的配合关系；根据常见结构的表达方法和规定画法识别零件；利用零件结构的对称性、两零件接触面大致相同的特点帮助想象零件结构形状。
3. **分析零件**：弄清每个零件的结构形状、功能和各零件间的装配关系。
4. **归纳总结**：在分析装配关系和主要零件结构的基础上，研究技术要求与全部尺寸，了解设计意图和装配工艺性。

## 由装配图拆画零件图

- **零件分类**：标准零件（列出标准件的汇总表）、借用零件（借用定型产品零件的图样，不必另行画图）、特殊零件（按设计说明书附有的图样或数据绘制）、一般零件（按装配图所示形状、大小和有关技术要求来画图，是拆画零件图的主要对象）。
- **表达方案**：零件图的表达方案根据零件的结构形状特点考虑，不一定与装配图一致。
- **结构形状**：装配图中未给出的零件局部结构，以及某些标准结构（如倒角、退刀槽），拆画时按设计要求和工艺要求补画出。
- **尺寸处理**：装配图上已注出的尺寸在零件图上直接注出；与标准件有关的尺寸（如螺纹尺寸）从相应标准中查取；明细栏中给定的尺寸（如垫片厚度）按给定尺寸注写；根据装配图所给数据应计算的尺寸（如齿轮分度圆直径）计算后注写；相邻零件接触面尺寸及连接件的定位尺寸要协调一致；由标准规定的尺寸（如倒角、沉孔）从手册中查取；其余尺寸按比例从装配图上量取，并注意尺寸数字的圆整。
- 零件上各表面的粗糙度根据其作用和要求确定；零件图中的技术要求直接影响加工质量，同样重要。

- 装配图上要标注哪几类尺寸？

- 看装配图的方法和步骤是什么？
