# 制图的基本知识和技能

## 知识点ID

G09

## 基本概念

国家标准《技术制图》是基础技术标准，《机械制图》是机械专业制图标准，它们是图样绘制与使用的准绳。“GB/T”表示推荐性国家标准。

图样必须按国家标准的规定表达，主要包括：图纸幅面与格式、比例、字体、图线、尺寸注法等。

## 核心规律

**图纸幅面与格式**：基本幅面有 A0、A1、A2、A3、A4 五种。图框用粗实线画出，图样绘制在图框内部；图框分为不留装订边和留装订边两种。标题栏位于图纸右下角。

**比例**：图样中图形与实物相应要素线性尺寸之比。分原值比例（1:1）、缩小比例、放大比例。同一机件各视图应采用相同比例，并在标题栏中标明；某视图比例不同应另行标注。

**字体**：图样中的字体应工整、笔画清楚、间隔均匀、排列整齐。字体的号数即字高 h（mm），公称尺寸系列为 1.8、2.5、3.5、5、7、10、14、20。汉字用长仿宋体，字高不小于 3.5 mm，字宽约 0.7h；数字和字母分 A 型、B 型，斜体字头向右倾斜 75°。

**图线**：基本图线有粗实线、细实线、细虚线、细点画线、细双点画线、波浪线、双折线等。粗实线画可见轮廓，细虚线画不可见轮廓，细点画线画中心线和对称线。虚线、点画线相交时应交于画或长画处；点画线两端应超出轮廓 2～5 mm。

**尺寸注法**：尺寸由尺寸界线、尺寸线、尺寸数字三要素组成。尺寸界线用细实线，超出尺寸线约 2～5 mm；尺寸线用细实线，必须与所标注线段平行；尺寸数字及相关符号按标准注写。

## 平面图形尺寸分析

- **基准**：确定尺寸位置的几何元素。一个平面图形至少有两个基准（X、Y 方向），常用对称中心线、较大圆的中心线、较长直线作基准。
- **定形尺寸**：确定各线段形状大小的尺寸（长度、直径/半径、角度）。
- **定位尺寸**：确定线段或线框间相对位置的尺寸。
- 圆弧按已知弧（圆心两坐标+半径齐全）、中间弧（两个尺寸）、连接弧（一个尺寸）分类，缺少的尺寸按相切条件作出。
- 画图步骤：画基准线和定位线 → 画已知线段 → 画中间线段 → 画连接线段。

## 尺规作图与徒手绘图

- 铅笔：HB 或 B 画粗线；H 或 HB 写字；2H 或 H 画细线及底稿。
- **斜度**：tan α = H:L = 1:n。**锥度**：正圆锥底圆直径与其高度之比，锥度 = 2tan(α/2) = D:L = (D−d):l。
- **圆弧连接**：用线段光滑连接两已知线段的作图。用半径 R 的圆弧连接两相交直线：作两直线的平行线（距离为 R）交于 O，即连接弧圆心，再找切点画弧。
- 徒手绘图（草图）：以目测估计比例徒手绘制，要求线稳图清、比例匀称、速度要快、注尺寸无误。

## 空间意义

制图基本知识是绘制和阅读工程图样的“语言规范”。图线粗细代表含义（可见/不可见/中心线），比例决定大小，尺寸决定形状与位置。掌握规范才能让图样“看得懂、画得对、标得清”。

## 作图方法

尺规绘图步骤：选图幅 → 画图框标题栏 → 布图画基准 → 画主要轮廓 → 画细节 → 检查修改 → 按先曲线后直线、先实线后其他线描深 → 注尺寸写文字 → 检查清洁。

## 典型问题

- 图线有哪几种？粗实线、细虚线、细点画线各表示什么？
- 什么是比例？原值比例与放大、缩小比例有何区别？
- 尺寸三要素是什么？各有什么规定？
- 什么是基准、定形尺寸、定位尺寸？
- 如何用圆弧连接两已知直线、两已知圆弧？
