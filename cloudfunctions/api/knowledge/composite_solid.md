# 组合体

## 知识点ID

G10

## 基本概念

组合体是由基本几何形体（棱柱、圆柱、棱锥、圆锥、圆球、圆环等）或简单形体（拉伸体、回转体等）组合构成的立体。

组合体的分析方法主要有：形体分析法、线面分析法，以及集合运算（并、交、差）与动平面轨迹（拉伸、旋转）分析。

## 核心规律

**集合运算**：叠加＝求并（∪）；挖切＝求差（＼）；求交＝求交集（∩）。CSG 法是把体素通过并、交、差运算构成复杂实体，CSG 树描述组合体构形过程。

**形体分析法**：假想把组合体分解为若干个形体（基本几何形体或简单形体），确定各形体之间的组合形式和相对位置。

**邻接表面关系**：共面、相切、相交。

- 共面：邻接表面共面处不应画分界线。
- 相切：相切处为光滑过渡，切线的投影规定不画；若切线处存在回转面转向线，则应画出该转向线的投影。
- 相交：相交处一定产生交线。

## 画组合体视图

步骤：形体分析 → 确定主视图（反映形体特征、符合自然安放位置）→ 选比例、定图幅 → 布图、画基准线（对称面、轴线、大平面）→ 逐个画出各形体三视图 → 检查、描深。

必要时用线面分析进行线、面投影分析；出现不完整形体相贯时可用恢复原形法。

## 看组合体视图

看图以形体分析法为主、线面分析法为辅。要点：

- 几个视图联系起来看，一个视图不能确定形状及相对位置；
- 从反映形体特征的视图入手；
- 用线框识别形体表面间的位置关系（相邻或嵌套线框可能表示相交面、高低错开的面、或面与孔洞）。

步骤：分线框、对投影 → 识形体、定位置 → 综合起来想整体。

## 标注组合体尺寸

- **定形尺寸**：确定各形体形状大小的尺寸（长、宽、高三个方向）。
- **尺寸基准**：确定尺寸位置的几何元素，常取对称平面、主要轴线、较大平面（底面/端面）。长、宽、高方向各有一个主要基准，辅助基准按需选用，主辅基准间应有尺寸联系。
- **定位尺寸**：确定形体间相对位置的尺寸；共面、对称、同轴时可省略一个定位尺寸。
- 标注要完整、清晰：标注在反映形体特征的视图上、关联尺寸集中、交线上不注尺寸、排列整齐。

步骤：形体分析 → 选三方向基准 → 注定形和定位尺寸 → 调整总体尺寸 → 检查。

## 空间意义

组合体是基本立体按一定方式构成的复杂形体，是工程零件的基础表达对象。掌握“形体分析 + 线面分析”、画/看三视图和尺寸标注，是正确表达和阅读零件图的前置能力。

## 作图方法

画图：先形体分析，再按“主视图优先、几个视图联系画”的顺序逐个画形体，最后检查描深。看图：先分线框找形体，再定相对位置，最后综合想象整体并验证各视图。
