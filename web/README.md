# 微信网页版

`web/index.html` 是画法几何互动课堂 Version 1.0 的网页入口。

## 本地测试

直接双击 `web/index.html`，或将它拖入 Chrome、Edge 浏览器打开。网页通过兼容层复用小程序的几何算法和 Canvas 绘图代码，不需要安装依赖或运行构建命令。

## 发布到微信公众号

微信公众号菜单不能直接访问电脑本地文件。发布时需要：

1. 将整个项目目录上传到支持 HTTPS 的静态网站空间，并保持 `web/` 与 `pages/` 的相对目录关系。
2. 确认公网地址能打开，例如 `https://example.com/web/index.html`。
3. 在公众号后台把自定义菜单设置为“跳转网页”，填写该 HTTPS 地址。
4. 如需使用微信网页授权、登录或集中学习记录，再配置公众号网页授权域名和服务端接口。

不要把公众号 AppSecret 写入 `index.html`、`runtime.js` 或任何前端文件。

## 当前范围

- 点、直线、平面与平面切割立体功能与小程序 Version 1.0 共用逻辑。
- 支持鼠标与触屏拖动、模块切换、截平面角度和位置调整。
- 当前版本不包含登录、云端学习记录或反馈收集。
