# 测试规范

## 现状（重要）

**本项目目前没有任何自动化测试。** 没有测试框架、没有测试用例、没有 CI。

所有验证均依赖：
- 微信开发者工具模拟器（可切 iPad / 自定义大屏机型）
- 真机预览（手机 / 平板）
- 云开发控制台（云函数日志、数据库记录核对）

因此：**不得声称"测试已通过"来指代不存在的自动化测试**。只能说明"在微信开发者工具 / 真机上实测了哪些场景"。也不得以"代码看起来合理"代替实测。

## 通用要求

1. 改动前先明确：本次要验证哪些场景、用什么设备/尺寸。
2. 触及几何或交互的改动，必须在**真机或模拟器**上实际操作，而非只读代码。
3. 涉及云函数的改动，**必须先在云开发控制台重新部署**，再验证；只改本地代码不算生效。
4. 涉及数据库的改动，先确认集合存在、字段结构，再验证读写。
5. 完成后向用户说明：验证了哪些项、用什么方式、哪些没验证。

## 一、几何回归测试

### 点
- 创建与类型切换：一般点、原点、H/V/W 面、OX/OY/OZ 轴
- 拖动三个投影点，验证空间点与另两个投影同步
- 三面投影关系正确（长对正 / 高平齐 / 宽相等）
- 投射连线与四分之一转向圆弧显示正确

### 线
- 创建与类型切换：一般线、水平线、正平线、侧平线、铅垂线、正垂线、侧垂线
- 拖动任一端点，真长与投影同步变化
- 三条投影线段与空间直线联动
- 零长度/重合端点不产生异常

### 面
- 创建与类型切换：一般面、水平面、正平面、侧平面、铅垂面、正垂面、侧垂面
- 三点共线时应有明确处理
- 特殊位置平面在对应投影面应积聚为直线
- 拖动顶点后三视图同步

## 二、平面切割立体

- 六种立体逐一测试：三棱锥、五棱柱、圆柱、圆锥、圆球、圆环
- 截平面类型：水平面、正垂面（连续角度 0°~180°）、侧平面
- 偏移量调整（平面位置）
- 截交线形状与位置正确；退化情形（相切、共面、过顶点）不崩溃
- 三视图中的截交投影与空间图来自同一数据
- 连续拖动角度/位置时流畅，松手后结果精确
- 曲面体（圆球、圆环）拖动跟手性可接受

## 三、基本立体

- 六种立体切换：棱柱、棱锥、圆柱、圆锥、圆球、圆环
- 棱数步进（3~8）
- 半径 / 高度 / 大小圆半径滑块
- 绕 X / Y / Z 旋转（角度滑块）与平移
- "旋转 90°"
- 重置：只重置当前立体，不得跳回棱柱（历史缺陷点）
- 三视图同步；对称中心线只在对称处出现；不可见轮廓用细虚线

## 四、AI 教师

- 正常提问 → 得到回答
- 连续多轮对话，上下文延续正确
- 知识点匹配（`cloudfunctions/api/ai/knowledge.js`）是否命中预期知识
- 名单内学生可提问；名单外被拒绝且提示清晰
- 异常：空消息、超长消息、上游 API 未配置 / 超时
- 图片问答当前默认关闭（`enableImage = false`），启用前需单独验证
- 改 Prompt 或知识库后：**重新部署云函数**再回归，且检查回答长度"不超过一屏"

## 五、教师后台

### 小程序端（`pages/teacher/`）
- 教师账号密码登录成功 / 失败提示
- 超级管理员可新增/停用/改密/删除教师
- 驾驶舱统计能取到数据
- 登录态过期后回到登录页
- 大屏（iPad 机型）下布局正常

### 网页端（`teacher-web/`）
- 需部署到已备案自定义域名后访问（默认域名会被风控拦截）
- 登录、驾驶舱、教师管理功能与小程序端一致
- 与小程序端共用同一 `teacher` 云函数，数据互通

## 六、通用体验

- 窄屏手机、平板、电脑三种尺寸下的布局
- 画布可交互区域的触摸/拖动正常
- 页面可上下滚动，拖动图形时不误触滚动
- 控制台无未处理报错

## 回归底线

任何改动后，至少要确认：
1. 首页能正常打开并绘制。
2. 点/线/面三种模式切换后仍能绘制与拖动。
3. 基本立体与平面切割立体仍能正常显示。
4. 学生登录/注册流程未被破坏。
